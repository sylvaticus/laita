Local AI Text Assistant

Local AI proofreading, powered by your own Ollama instance. No text ever leaves this machine.

Model

0 gives the most repeatable corrections.
0 follows Ollama's own setting, and is what you want: naming a different size here makes Ollama unload whatever another app (Open WebUI, say) has running and load a second copy of the same model. Pin a number only to override the server on purpose.
How many paragraphs are sent at once. Leave at 1 unless you have raised OLLAMA_NUM_PARALLEL: Ollama handles one request at a time by default, so the rest only sit in its queue while their timeout runs down.
Avoids a slow reload on every check. Needs a unit — 30m, 8h. Use -1m, or any negative value, to keep the model loaded indefinitely; a bare -1 is rejected by Ollama.

When to check

Opening a long document with the whole field sends one request per paragraph before you have typed anything — slow, and hard on the model. Paragraphs you have already visited keep their highlights either way, and Alt+Shift+C or the toolbar button always checks everything.
How long you have to stop typing before a check starts. Shorter means more requests for text you are still changing, and the model does not answer instantly either — a paragraph takes seconds, not milliseconds.
Keeps search boxes, usernames and one-line forms out of it. There is nothing useful to say about three words, and asking costs a round trip anyway.
Longer paragraphs are split on sentence boundaries, so that typing in one checks only the part you are editing. Nearly all the time goes on the model writing its answer, not on reading your text, so a smaller size means a faster reply while you type. It also finds more: a single request stops at twelve suggestions, so splitting a long paragraph can surface issues a whole-paragraph check would never reach. Raise it only if suggestions are missing context that spans sentences.
How much text one check may send, not how long a field may be. With only the paragraph I am working in above, a paragraph is well under this however long the document is; only a whole-field check can exceed it. Also caps a single Transform.

Language

Transform selected text

Select text on any page, right-click and choose LAITA › Transform… (or press Alt+Shift+T), then type what you want done with it — polish, translate to French, shorten it. The result can replace the selection or be inserted after it.

What to report

Spelling, agreement, conjugation, punctuation.
Wordiness, redundancy, register, repetition.
Better words, more natural formulations.

Where to run

Pausing on a site from the right-click menu, Alt+Shift+X or the toolbar button overrides these lists for that one hostname, so a pause holds whatever the policy above says. Clear those overrides under Maintenance.

LAITA never reads password, payment or one-time-code fields, nor any field — including rich-text ones — whose own name, label or class, or that of an enclosing container, suggests a secret, a payment, a bank, a recovery phrase, or medical or identity data. That list is a denylist, so it cannot be complete: a field with an innocuous name holding sensitive text is read like any other, and it protects fields rather than content. Add data-laita="off" to any element to exclude it and everything inside it.
